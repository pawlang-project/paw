## 📝 语法速查

### 函数

```paw
fn name(x: i32) -> i32 { return x; }
fn generic<T>(x: T) -> T where T: Display { }
```

### 类型

```paw
type Point = struct { x: i32, y: i32 }
type Option<T> = enum { Some(T), None }
type Display = interface { fn show(); }
support Point with Display { fn show() { } }
```

### 变量

```paw
let x = 10;           // 不可变
let~ y = 20;          // 可变（~表示可变）
let z: i32 = 30;
let (a, b) = (1, 2);
```

### 控制流

```paw
if x > 0 { } else { }
loop { }
loop i in 0..10 { }
loop item in arr { }
break; continue; return;
```

### 模式匹配

```paw
x is {
    Some(v) => v,
    None => 0,
    _ => default,
}
```

### 类型转换

```paw
x as i64
x as f64
```

### Optional和Result ⭐ v1.4.2

```paw
// Optional (T?) - 可选值
let name: string? = some("Alice");  // some() 构造
let empty: i32? = none;             // none 空值
if empty == none { }                // none 检查

// 模式匹配
name is {
    some(val) => val,
    none => "Unknown"
}

// Result (T!) - 错误处理
fn divide(a: i32, b: i32) -> i32! {
    if b == 0 { return err("error"); }
    return ok(a / b);
}
let x = divide(10, 2)!;  // Try表达式

// 组合类型
fn db_query() -> User?! {  // T?! = Result<Optional<T>>
    return ok(none);  // 或 ok(null)
}
```

## 🎓 常用模式

### 错误处理

```paw
fn operation() -> T? {
    let x = step1()?;
    let y = step2()?;
    return ok(result);
}
```

### 闭包

```paw
let add = (x: i32, y: i32) -> i32 {
    return x + y;
};
let result = add(10, 20);
```

### 迭代数组

```paw
loop item in array {
    println(item);
}
```

### 泛型函数

```paw
fn swap<T, U>(a: T, b: U) -> (U, T) {
    return (b, a);
}
```

### Where约束

```paw
support Box<T> with Display where T: Display {
    fn show() { self.value.show(); }
}
```
